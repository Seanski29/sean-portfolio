Sean Martin Del Rosario's personal portfolio, rebuilt with React, Vite, Tailwind CSS, and Lucide React icons.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

After signing in to Vercel:

```bash
npx vercel
```

For production:

```bash
npx vercel --prod
```
